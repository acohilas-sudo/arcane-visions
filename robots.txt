# opts INTO AI-search discovery and citation (ClaudeBot, GPTBot, PerplexityBot,

# discovery channel for collectors and practitioners who use AI search tools.

# a block that DISALLOWS these same agents ahead of this file at the edge. That

# seen in the served robots.txt. For this allow-policy to actually take effect,
# Cloudflare AI Crawl Control must remain DISABLED in the dashboard
# (zone arcanevisions.art -> Security/Bots -> AI Crawl Control / managed robots).
# Deploying this file does not change that edge setting.
